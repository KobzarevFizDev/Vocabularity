## Для чего проект

Проект предназначен для изучения английского языка. Смысл в том чтобы извлекать лексику из книг, видео и других источников
и добавлять ее в базу для изучения.

## Как работает проект

- Агент анализирует текст или видео, находит лексику для изучения.
- Отправляет запрос на mcp, чтобы предложить пользователю изучить эту лексику.
- mcp отправляет запрос на backend.
- backend через websocket передает список слов, которые он рекомендует изучить пользователю.
- Пользователь выбирает слова и они сохраняются в базе.

## Структура проекта

- vocabularity.backend - Предназначен для работы с БД, хранит карточки слов для изучения. Имеет связь по websocket с фронтенд частью для передачи команд.
- vocabulrity.frontend - Предназначен для отображения карточек слов и другой информации, через websocket может выполнять различные команды: Переключить страницу, добавить или удалить карточку.
- vocabularity.mcp - Интерфейс для агента.

## Docker

- docker compose up -d --build frontend Чтобы пересобрать фронтенд

На этом ПК — пересобрать и сохранить всё в один архив:

docker compose build
docker save -o vocabularity-images.tar vocabularity-backend vocabularity-frontend vocabularity-mcp vocabularity-migrator

Перенести на другой ПК два файла:

- vocabularity-images.tar
- docker-compose.yml (и при желании .env с паролем БД)

На другом ПК:

docker load -i vocabularity-images.tar
docker compose up --no-build

--no-build обязателен: исходников там нет, поэтому compose не должен пытаться собирать. Postgres подтянется сам.
