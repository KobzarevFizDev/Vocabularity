## О проекте

Это фронтенд часть. Отвечает за отображение карточек слов.

## Переменные окружения

Все переменные, такие как url, порты и тд находятся в .env файле.
Значения из этого файла автоматические вшиваются в бандл после сборки.
Никакие переменные в проде настраивать не нужно.

## Генерация фронтенд части

Клиентская часть (dto, запросы) руками не пишется. Вместо этого используется кодогенерация на основе openapi-typescript.
Для генерации нужно скачать openapi.json со swagger и поместить его в каталог api (данный каталог создан руками).
Дальше нужно вызвать npm скрипт openapi-gen

## Команды

Данные команды/скрипты прописаны в package.json

- npm run dev - запускает сервер разработки
- npm run openapi-gen - запускает генерацию клиентской части на основе openapi.json

## Моки

В проекте используются MSW для моков
